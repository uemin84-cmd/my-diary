# 가계부 ↔ 구글 시트 연동 방법

가계부 앱(`budget.html`)은 Google Apps Script 웹 앱을 통해 구글 시트에 기록을 저장하고 불러옵니다.
별도 서버나 API 키 없이, 내 구글 계정 권한으로 동작합니다.

## 1. 구글 시트 만들기
1. [sheets.new](https://sheets.new) 에서 새 스프레드시트를 만듭니다. (이름 예: `가계부`)
2. 시트 탭은 따로 만들 필요 없습니다. 첫 기록 때 `가계부` 탭과 머리글이 자동으로 생성됩니다.

## 2. Apps Script 붙여넣기
1. 시트 메뉴에서 **확장 프로그램 → Apps Script** 를 엽니다.
2. 기본 `Code.gs` 내용을 지우고 이 폴더의 `Code.gs` 내용을 통째로 붙여넣습니다.
3. (권장) `const TOKEN = '';` 에 아무도 모를 문자열을 넣습니다. 예: `const TOKEN = 'my-secret-1234';`
4. 저장(💾)합니다.

## 3. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**
2. 유형 선택(⚙️) → **웹 앱**
3. 설정
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** → 권한 승인(“고급 → 안전하지 않은 페이지로 이동”을 눌러 진행해도 됩니다. 내가 만든 스크립트라서 뜨는 경고예요)
5. 표시되는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

## 4. 앱에 연결
1. 가계부 앱 → **⚙️ 구글 시트 연동 설정**
2. 웹 앱 URL 붙여넣기, 3번에서 TOKEN을 정했다면 같은 값을 **비밀 키**에 입력
3. **🔄 지금 동기화** → “동기화 완료!”가 뜨면 성공

## 동작 방식
- 기록하면 기기(localStorage)에 먼저 저장하고 바로 시트로 전송합니다.
- 오프라인 등으로 전송에 실패하면 “전송 대기”로 표시되고, 다음에 앱을 열거나 동기화할 때 다시 보냅니다.
- 앱을 열 때 시트 내용을 불러오므로, 시트에서 직접 고친 내용도 앱에 반영됩니다. (`ID` 열은 지우거나 바꾸지 마세요)
- 시트 열: `ID | 날짜 | 구분 | 카테고리 | 금액 | 결제수단 | 메모 | 입력시각`

## Code.gs를 수정했다면
**배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** 를 해야 반영됩니다. (URL은 그대로 유지)

## 한 줄 입력 문법
| 입력 | 결과 |
|---|---|
| `점심 김밥 12500` | 지출 · 식비 · 12,500원 |
| `택시 1만2천 어제` | 어제 날짜로 교통 12,000원 |
| `마트 장보기 3.5만 현금` | 식비 35,000원, 결제수단 현금 |
| `+월급 300만` | 수입 · 급여 3,000,000원 (`+`로 시작하거나 월급·이자 같은 단어가 있으면 수입) |

카테고리는 단어로 자동 추측하고, 틀리면 입력창 아래 칩을 눌러 바꾸면 돼요.

## 아이폰 단축어로 바로 기록하기
1. 단축어 앱 → 새 단축어
2. **입력 요청**(텍스트, "얼마 썼어요?") 추가
3. **URL 열기** 추가 → `https://내사이트주소/budget.html?q=` 뒤에 '제공된 입력' 변수 연결
4. 홈 화면이나 뒷면 탭에 단축어를 연결하면 앱을 찾지 않고 바로 기록할 수 있어요
